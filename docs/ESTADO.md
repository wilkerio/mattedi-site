# Mattedi — estado

Atualizado em 05/10/2026.

## Feito
- Site de uma página em `app/` (Vite + React + TS + Tailwind + framer-motion + Lenis). Rodar: `cd app && npm install && npm run dev` (porta 5290). Build: `npm run build`.
- Versão 2 (menos artificial): fotos reais no lugar do olival desenhado, rolagem nativa, sem efeitos de destaque. Fotos de banco em `app/public/img/` (créditos em `credits.json` e no rodapé).
- Seções: capa com foto, colheita (calendário), cultivo, azeites (seletor com garrafa), onde comprar, rodapé.
- Verificado: build limpo, sem erro de console, sem rolagem horizontal, teste de acessibilidade (axe, WCAG A/AA) sem violações, seletor de azeites por mouse e teclado, menu do celular, movimento reduzido.
